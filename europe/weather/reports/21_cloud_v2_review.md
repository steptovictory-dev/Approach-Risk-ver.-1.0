# 21. Обновленное представление облачных групп METAR

## 1. Изменение и область применения

Версия `cloud-v2` поддерживает короткие `///CB` и `///TCU` в наблюдаемой
части сообщения до температуры/QNH. Сохраняются тип облака, исходный токен
и неизвестные количество/высота. Их смысл проверен по
[Météo-France, Guide aviation 2021, печатная страница 17](https://meteofrance.fr/sites/meteofrance.fr/files/files/editorial/guide_aviation_2021.pdf).

Группа `/////////` сохраняется как облачная информация с отсутствующими
компонентами. При сравнении с python-metar учитывается, что сторонний парсер
не создает отдельный слой для полностью отсутствующих характеристик.
Это изменение проверки представления, а не восстановление метеоизмерения.

Для короткого CB/TCU флаг типа становится True. Количество остается
неизвестным, высота — пропуском. Если в сообщении есть другой известный слой,
его высота сохраняется как известная; потолок BKN/OVC при неизвестном
количестве одного из слоев не считается установленным. Нельзя автоматически
считать неизвестный слой самым высоким или присваивать ему FEW/BKN/OVC.

## 2. Версии и расположение данных

Отдельная папка на верхнем уровне проекта не создается. Внутри существующей
игнорируемой `europe/weather/data/` выделена версия `full_cloud_v2/`:

| Подкаталог | Содержимое |
| --- | --- |
| `reports/` | Обновленные декодированные сообщения, по станции и году. |
| `features/` | Полный набор связей с обновленными облачными полями и статусами. |
| `numeric_features/` | Числовые исходные/модельные копии с сохраненными масками CP-10. |

Предыдущие `data/full/results/`, `data/numeric_quality_v1/` и модули
`decode_metar.py`, `core_audit.py` сохранены. Новые модули:
`decode_metar_cloud_v2.py`, `core_audit_cloud_v2.py`.
Основной `full_weather_pipeline.py` остается воспроизводителем прежнего этапа;
версия v2 создается отдельным `rebuild_cloud_v2.py` без новой загрузки архивов.

Соединять полный и числовой набор одной версии по `source_row`, сверяя
SHA-256 входа. Суффикс `_model` сохраняется. Полный набор содержит исходные
числовые значения: использование их напрямую вместо модельной копии обходит
принятые маски и не является согласованным способом подготовки признаков.

## 3. Проверки

Обновлены 1 339 уникальных сообщений с целевыми группами. Полное декодирование
теперь проходит для 1 323 из них; у 16 остаются другие ошибки строгого парсера.
Число остаточных сообщений уменьшилось с 2 425 до 1 102.

Все 6 331 485 строк и 18 349 GoA сохранены. При давности до 60 минут,
задержке 0 и сохранении COR число строк с успешным полным декодированием
возросло с 6 322 498 до 6 325 385, с успешным основным префиксом —
с 6 324 868 до 6 327 940. Это техническое покрытие, не оценка эффекта на модель.

Набор отличается только облачными полями и связанными результатами проверки;
изменения записаны по каждому сообщению и полю. Связи METAR с посадками
и не относящиеся к облачности числовые значения не изменены.

- Шесть новых семантических тестов проверяют короткие типы, неизвестные
  характеристики, потолок, полные облачные пропуски и границу прогноза.
- Все 18 439 исходных сообщений двух пилотов воспроизведены по всем
  ранее сохраненным полям без изменений.
- Полный архив проверяется на принадлежность к области изменения;
  повторно декодируются только целевые сообщения. Для остальных модуль v2
  вызывает прежний декодер, результаты сохраняются без изменения.
- Каждый созданный файл прочитан повторно и сравнен с ожидаемым результатом.
- Проверены сохранность всех строк и меток, исходного текста, станции,
  временных связей, значений вне облачной области и всех числовых масок CP-10.
- Контрольные суммы предыдущих файлов проверяются до и после обработки.

Итоговые числа и полный журнал представлены в
[машиночитаемом результате](21_cloud_v2_application.json),
[регистре целевых сообщений](21_cloud_v2_cases.csv),
[изменениях полей](21_cloud_v2_field_changes.csv),
[сводке покрытия](21_cloud_v2_coverage.csv) и

## 4. Границы вывода

Улучшение декодирования не устраняет неполноту исходных наблюдений и
числовые аномалии. Никакие неизвестные высоты или количества не восстановлены.
Прогнозные группы и последующие сообщения не используются для подстановки.
Исправлены представление и проверки, а не исходные тексты METAR.

Остаточные погодные сочетания, состояние ВПП, нетипичные обозначения тренда
и другие форматы требуют отдельных проверок. Обучение, импутация, удаление
посадок и оценка влияния на модель не выполнялись.

Результат воспроизводится в [ноутбуке 12](../notebooks/12_cloud_format_update.ipynb),
включающем код, таблицы, сравнение версий, два рисунка и 26 тестов.
