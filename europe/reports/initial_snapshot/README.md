# Предварительный аудит европейского источника

Эти отчеты сформированы до создания отдельной папки Европы и ноутбука 01. Пути внутри отчетов отражают прежнее расположение исходника. Текущий файл находится в `europe/data/source/osn23_landings_merged.parquet.gzip`; актуальный полный аудит расположен в родительской папке `europe/reports`.

Снимки не являются очищенным набором и не заменяют новый полный аудит.
