# 06_04 – Поля погодного архива

Источник определений: [IEM](https://mesonet.agron.iastate.edu/request/download.phtml). Все исходные CSV сохранены без нормализации. Значение M означает пропуск или состояние, признанное архивом пропуском; причина по M не устанавливается. T сохраняется как следовое значение. Числовая сводка ветра получена из первой основной группы ветра исходного METAR; используется KT. Отсутствующий G не превращается в нулевой порыв.

| Поле | Смысл и единицы |
| --- | --- |
| station | Код станции METAR; сверяется с аэропортом и текстом сообщения |
| valid | Время наблюдения; запрос выполнен с tz=Etc/UTC |
| lon | Долгота станции, градусы |
| lat | Широта станции, градусы |
| elevation | Высота станции, м |
| tmpf | Температура воздуха, °F; в таблице не меняется |
| dwpf | Температура точки росы, °F |
| relh | Относительная влажность, % |
| drct | Направление ветра от истинного севера, градусы; не магнитное направление ВПП |
| sknt | Скорость ветра, kt |
| p01i | Осадки за расчетный час, дюймы; для станций вне США IEM отмечает недоступность, поле не используется |
| alti | Altimeter setting, inHg; не подменяет mslp или QFE |
| mslp | Давление, приведенное к уровню моря, mb; не подменяет alti или QFE |
| vsby | Видимость, мили; отдельно от исходной группы видимости METAR |
| gust | Сообщенный порыв ветра, kt; пропуск не означает отсутствие порывов |
| skyc1 | Код покрытия облачностью слоя 1 |
| skyc2 | Код покрытия облачностью слоя 2 |
| skyc3 | Код покрытия облачностью слоя 3 |
| skyc4 | Код покрытия облачностью слоя 4 |
| skyl1 | Высота слоя 1, ft по описанию IEM |
| skyl2 | Высота слоя 2, ft по описанию IEM |
| skyl3 | Высота слоя 3, ft по описанию IEM |
| skyl4 | Высота слоя 4, ft по описанию IEM |
| wxcodes | Коды текущих погодных явлений по декодеру IEM |
| ice_accretion_1hr | Нарастание льда за 1 час, дюймы; не используется |
| ice_accretion_3hr | Нарастание льда за 3 часа, дюймы; не используется |
| ice_accretion_6hr | Нарастание льда за 6 часов, дюймы; не используется |
| peak_wind_gust | Пиковый порыв из PK WND, kt; отдельно от основного поля gust |
| peak_wind_drct | Направление пикового ветра, градусы |
| peak_wind_time | Время пикового ветра по архиву; формат и доступность отдельно не проверялись, не используется |
| feel | Расчетная ощущаемая температура, °F; не используется |
| metar | Исходное переданное сообщение METAR; основной материал проверки |
| snowdepth | Поле снежного покрова IEM; единицы и полнота здесь не проверены, не используется |

Производные поля: `flight_id` – связь с записью полета; `observation_utc` и `metar_utc` – время наблюдения в UTC; `event` – номер попытки или посадка; `event_utc` – время события в UTC; `age_minutes` – возраст последнего предшествующего сообщения, минуты. Поля `daily_*` относятся к полному UTC-дню, `event_*` – только к выбранным предшествующим METAR; `daily_reports` и `event_metars` – количество сообщений. Поля `*_kt` выражены в узлах, `event_max_metar_age_minutes` – в минутах. `all_event_reports_CAVOK` показывает наличие группы CAVOK во всех выбранных сообщениях. Поля `wind_direction_group`, `wind_speed_kt`, `wind_gust_kt` извлекаются из первой группы ветра; VRB сохраняется как переменное направление.

Группы Qxxxx в исходных европейских METAR сохраняются; давление в этой проверке не служит правилом исключения. Значения alti, mslp и исходные группы давления не смешиваются.
