# C40 – Подготовка эксперимента при входе в область C40

Один шаг – один ноутбук. Работаем с Европой 2019–2023. Шаги 04_01–04_07 исследуют копию `03_c40_diagnostic_flags.parquet`; после согласованного шага 04_08 вход аудита 04_09 – `04_c40_ambiguous_pairs_excluded.parquet`. После 04_10 актуальная выборка эксперимента – `europe/data/analytical/04_c40_available.parquet`.

- [04_01 – Постановка задачи](04_01_task_definition.ipynb): единица наблюдения, целевая метка, варианты момента прогноза и открытые решения; без изменения базы
- [04_02 – Доступность признаков](04_02_feature_availability.ipynb): карта всех 31 поля, полный подсчет пропусков и оценка последствий отбора по C40; без фильтрации
- [04_03 – Покрытие C40](04_03_c40_coverage.ipynb): аэропорты, месяцы, сегменты и три графика; данные сохранены
- [04_04 – Сопоставление C40](04_04_c40_matching.ipynb): полный поиск повторных отметок и неоднозначных контекстов; очистка отложена
- [04_05 – Разбор 147 пар](04_05_c40_pair_review.ipynb): сравнение всех исходных полей, времен и меток; обе строки каждой пары сохранены
- [04_06 – Материалы трех пар](04_06_independent_check.ipynb): опубликованные траекторные точки, независимая проверка этих трех событий пока не завершена
- [04_07 – Проверка по открытым измерениям](04_07_public_pair_check.ipynb): одна пара LFPG проверена по публичным снимкам OpenSky без Trino
- [04_08 – Исключение неоднозначных пар](04_08_exclude_ambiguous_pairs.ipynb): по решению пользователя исключены обе строки 147 пар из новой копии, 294 записи и три GoA=True
- [04_09 – Доступность C40 после исключения пар](04_09_c40_selection_audit.ipynb): строгий порядок времен, полнота и конечность значений, последствия отбора по аэропортам, годам и сегментам; без фильтрации
- [04_10 – Применение отбора C40](04_10_apply_c40_selection.ipynb): отдельная выборка 6 331 494 строк и 18 358 GoA=True; исключенные из эксперимента строки сохранены отдельно
- Далее – обоснованный отбор записей и аэропортов с оценкой влияния каждого правила

Входы и история преобразований: [подготовка 03](../03_data_preparation/README.md).

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe europe/scripts/execute_analytical_sample.py --step 04_02
```

Согласовано: все наблюдаемые полеты, включая специальные; прогноз в точке входа C40. Исключение 147 неоднозначных пар выполнено отдельно в 04_08, дальнейший разбор этих пар закрыт. В 04_10 применено правило доступности C40 из 04_09. Строки вне эксперимента сохранены отдельно; дополнительные ограничения по аэропортам, группам полетов и числу попыток не применялись. Окончательный набор признаков остается открытым. Исторические отчеты 04_02–04_07 описывают базу до исключения; их счетчики не являются счетчиками новой копии.

Полный реестр `reports/analytical_sample/04_04_same_day_contexts.csv` сохранен локально и исключен из Git из-за объема. Его формирует `scripts/audit_c40_matching.py`; сводные результаты проверки включены в репозиторий.
