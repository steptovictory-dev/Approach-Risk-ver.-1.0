## Воспроизведение

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -u -X utf8 europe/scripts/execute_attempts.py --step 06_05
```

Доступны шаги 06_01–06_05. Каждый ноутбук работает со своим зафиксированным историческим входом; его исходные счетчики не описывают автоматически последнюю выборку. Скрипты исключения защищены от повторной перезаписи выходов.

Количество отметок не равно подтвержденному количеству эксплуатационных уходов. Интервалы измерены между отметками детектора, а не как длительность маневра. Для LSGG остается запланированная проверка чувствительности при моделировании; это не незакрытое решение по очистке этапа 06.
