# 03 – Подготовка данных Европы 2019–2023

Каждый шаг – отдельный ноутбук. Выполняйте ячейки сверху вниз в отдельном ядре окружения проекта. Переменные соседних ноутбуков не нужны; входные файлы и справочники должны существовать.

| Шаг | Ноутбук | Вход и результат |
| --- | --- | --- |
| 03_01 | [Диагностика пропусков](03_01_missing_values.ipynb) | Исходник; только анализ |
| 03_02 | [Нормализация пустых строк](03_02_normalize_empty_strings.ipynb) | Исходник → копия 01; три согласованных поля и обратимые флаги |
| 03_03 | [Классификации](03_03_aircraft_codes.ipynb) | Копия 01; диагностика |
| 03_04 | [Справочные предложения](03_04_reference_review.ipynb) | Копия 01 и сохраненные предложения; проверка |
| 03_05 | [Обогащение](03_05_apply_aircraft_reference.ipynb) | Копия 01 → копия 02; исходные поля сохранены |
| 03_06 | [Неразрешенные классификации](03_06_unresolved_aircraft.ipynb) | Копия 02; изменения отложены |
| 03_07 | [Диагностика C40](03_07_c40_diagnostics.ipynb) | Копия 02; анализ времен |
| 03_08 | [Флаги C40](03_08_apply_c40_flags.ipynb) | Копия 02 → копия 03; три флага |
| 03_09 | [Повторяющиеся flight_id](03_09_flight_ids.ipynb) | Копия 03; строки сохранены |
| 03_10 | [Несколько попыток](03_10_attempts.ipynb) | Копия 03; изменения отложены |

03_02 повторяет подготовку входа из 03_01 для самостоятельного запуска. Данные остаются в `europe/data/`, отчеты и журналы – в [reports/preparation](../../reports/preparation/). Актуальный вход дальнейших этапов: `europe/data/working/03_c40_diagnostic_flags.parquet`.

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe europe/scripts/execute_preparation.py --step 03_10
```

Указывайте ровно один шаг. Прежние ключи отдельных диагностических запусков поддерживаются. Запуск 03_02, 03_05 или 03_08 заново формирует рабочую копию и журнал соответствующего преобразования.

[Общий ноутбук 03](archive/03_data_preparation.ipynb) убран в архив как история выполненных шагов; его сохраненные результаты перенесены в отдельные ноутбуки. Рабочие файлы – 03_01–03_10. Скрипт `split_preparation_notebooks.py` предназначен для первоначального переноса; повторный запуск перезаписывает отдельные версии. Генератор общего ноутбука работает только с архивной версией.

Следующий этап формирования аналитической выборки будет в отдельной папке 04 с именами `04_01`, `04_02` и далее.
