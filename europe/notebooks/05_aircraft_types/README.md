# 05 – Типы воздушных судов

Один шаг – один ноутбук. Вход этапа: `europe/data/analytical/04_c40_available.parquet`, сформированный после завершения C40.

- [05_01 – Аудит типов ВС](05_01_aircraft_types_audit.ipynb): пропуски, сочетания кодов, справочные статусы и пять неразрешенных значений; без изменения базы

- [05_02 – Разбор пропусков типов](05_02_missing_types_review.ipynb): 911 положительных меток, структура пропусков, расширенная история адресов и кандидаты; без исправлений

Отчеты: `europe/reports/aircraft_types/`. История справочных решений и официальные источники сохранены в этапе 03. При оценке классификаций не считаем отсутствие типа основанием признать весь полет ошибочным.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -u -X utf8 europe/scripts/execute_aircraft_types.py --step 05_01
```

- [05_03 – Восстановление классификации](05_03_restore_classification.ipynb): прямое сопоставление с ICAO, отдельные производные поля, без удаления строк

После 05_03 актуальная рабочая копия – `europe/data/analytical/05_aircraft_classification_enriched.parquet`. Ноутбуки 05_01–05_02 описывают вход до этого обогащения.

- [05_04 – Обозначения моделей и пробелы](05_04_model_names_restoration.ipynb): еще 8 510 классификаций по ICAO, включая 18 GoA=True; без удаления строк

После 05_04 актуальная копия – `europe/data/analytical/05_aircraft_model_names_enriched.parquet`.

- [05_05 – Завершение разбора](05_05_finish_type_review.ipynb): еще 7 727 классификаций, включая 32 GoA=True; неразрешенный остаток сохранен

Этап 05 завершен в согласованном ограниченном объеме. Актуальная копия – `europe/data/analytical/05_aircraft_types_reviewed.parquet`. Остаток не удален и не заполнен предположениями. [Итог этапа](../../reports/aircraft_types/05_05_review.md).
