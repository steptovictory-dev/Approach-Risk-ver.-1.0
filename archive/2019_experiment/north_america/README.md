# Северная Америка: данные, контекст и исследование качества

Ветка: `data-cleaning/north-america`. Исходные записи не удаляем и не исправляем
без установления причины и явного решения автора проекта.

## Структура

| Папка | Содержимое |
| --- | --- |
| `data/source/` | Перемещенный региональный CSV с проверенным SHA256 |
| `data/review/` | Полные копии записей с флагами и номерами исходных строк |
| `data/derived/` | Основная аналитическая выборка `us_canada.csv` с согласованным отбором |
| `documents/` | Официальные документы по юрисдикциям, реестр и источники |
| `literature/` | Аннотированная библиография, DOI, BibTeX, локальные открытые PDF |
| `reports/` | Проверяемые агрегаты, примеры и выводы |
| `figures/` | Экспорт графиков в PNG и SVG, включая исследование KSFB |
| `notebooks/` | Региональный ноутбук с отдельными ячейками графиков |
| `scripts/` | Повторяемая проверка данных и скачивание документов |

CSV и скачанные PDF остаются локально вне Git. Ссылки, библиография,
небольшие агрегаты и код доступны для версионирования. Примеры отдельных
записей, индекс страниц PDF и сырой ответ Crossref остаются локально.
Содержимое внешних документов не изменяем: оформление проекта не применяется
к оригинальным PDF и точным библиографическим названиям.

## Ограничения

Преобладают США; Карибские территории представлены очень мало.
Диагностический флаг не равен ошибке и не является основанием удаления.
Высота перехода, IAS и выбранная процедура отсутствуют в этой таблице:
проверку их соблюдения нельзя имитировать погодными или справочными полями.

Критерий точности и основания всех исключений: [реестр решений](reports/selection_rationale.md). Допуск 0,2 п.п., двусторонний интервал Уилсона 95%. Дополнительные исключения автоматически не применены
