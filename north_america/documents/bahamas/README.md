# Багамы: источники и покрытие

Регулятор: [Civil Aviation Authority Bahamas](https://caabahamas.com/).
Официальный раздел [CARs Air Navigation Services](https://caabahamas.com/air-navigation-services/)
содержит документы ATS, MET и другие регламенты.
Нормы для конкретного аэропорта и периода пока не разобраны.

В нашей региональной таблице всего одна запись BHS. На таком объеме
нельзя оценить характерную долю уходов или сравнить безопасность страны.
