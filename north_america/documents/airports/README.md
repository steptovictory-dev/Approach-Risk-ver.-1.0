# Контекст аэропортов

Полный список 74 аэропортов и их объемы: [airport_summary.csv](../../reports/airport_summary.csv).
Справочник пока не содержит подтвержденных названий, штатов, координат,
высот и процедур. Эти значения не угадываем по ICAO-коду.

Для аэропорта добавляем отдельную папку после получения официального материала.
В карточке фиксируем: источник, цикл AIRAC, период действия, систему высот,
давление, переходную высоту/эшелон, ограничения скорости, навигацию и связь.
Пустое значение означает «не подтверждено», а не «ограничений нет».
