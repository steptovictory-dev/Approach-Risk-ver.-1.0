# Литература и первичные документы

Загрузчик: из корня проекта `.\.venv\Scripts\python.exe -u -X utf8 research/c40_geometry/scripts/fetch_literature.py`.

`source_manifest.json` содержит название, автора/организацию по документу, URL, дату документа или AIRAC-среза, назначение, место проверки, статус получения, размер и SHA256. Статус `saved` подтверждает локальный PDF; неуспешные загрузки явно отмечены как `failed`. Дата получения не подменяет дату действия документа. Локальные копии находятся в `files/` и не публикуются через Git автоматически.

| Источник | Для чего нужен |
| --- | --- |
| Figuet et al., 2023 | Происхождение C40 и объединение EU-NM/OpenSky |
| EUROCONTROL, Technical Note 2011 | Историческая методика ASMA 40 NM |
| EUROCONTROL OPADD 4.1 | Значение координат и радиуса географической ссылки NOTAM |
| EUROCONTROL AVENIR, 2025 | Позднее изменение методики первого/последнего входа; отдельный временной контекст |
| Vincenty, 1975 | Расстояние по эллипсоиду |
| Karney, Algorithms for geodesics | Современная геодезическая методика; arXiv-версия проверяется отдельно |
| Исторические схемы UK AIP EGLL/EGCC | Пилот независимой проверки центра; срезы 2019–2023 |

Схемы с координатами в заголовке помогают пилоту, но дальнейший реестр должен по возможности опираться на AD 2.2 и историю изменений. Сторонние перепечатки и симуляторные базы не подменяют официальный источник. Научный обзор еще не завершен.
