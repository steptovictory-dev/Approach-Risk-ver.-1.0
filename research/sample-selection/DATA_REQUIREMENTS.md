# Контракт внешних данных

Корень данных задается через `SAMPLE_SELECTION_DATA_ROOT`. Структура путей сохраняется для явного происхождения артефактов. Полные массивы не копируются в исследование. Нужны следующие Parquet:

| Путь внутри корня | Назначение |
| --- | --- |
| `europe/data/source/osn23_landings_merged.parquet.gzip` | Исходная популяция |
| `europe/data/working/04_c40_ambiguous_pairs_excluded.parquet` | После исключения пар |
| `europe/data/analytical/04_c40_available.parquet` | После условий C40 |
| `europe/data/analytical/06_05_cases_excluded.parquet` | Финальная популяция |
| `europe/data/review/04_05_c40_pair_full_records.parquet` | 294 исключенные записи пар |
| `europe/data/review/06_02_lsgg_excluded_record.parquet` | Один согласованный случай |
| `europe/data/review/06_04_cfl12_excluded_record.parquet` | Один согласованный случай |
| `europe/data/review/06_04_excluded_profile_records.parquet` | Четыре согласованных случая |
| `europe/data/review/06_05_excluded_records.parquet` | Три согласованных случая |

JSON-журналы из `europe/reports/` перечислены в ячейке происхождения ноутбука. Их список намеренно явный: отсутствующий журнал останавливает выполнение. Полный массив без входов не воспроизводится из одних итоговых CSV.

## Поля, используемые в эксперименте

| Поле | Смысл и роль |
| --- | --- |
| `flight_id` | Идентификатор источника; часть ключа, не уникальный самостоятельно |
| `icao24` | Адрес борта; часть ключа |
| `airport` | Аэропорт события; ключ и группировка |
| `landing_time` | Время события UTC; ключ, календарные год и месяц аудита |
| `GoA` | Булева исходная метка; null останавливает расчет |
| `attempt_times` | Список времен попыток; первый элемент задает временной критерий |
| `C40_CROSS_TIME` | Время точки C40; полнота, согласованность и проверка сохранности |
| `C40_BEARING` | Числовое поле направления C40; проверка заполненности и конечности |
| `C40_CROSS_LAT`, `C40_CROSS_LON` | Координаты C40; проверка заполненности и конечности |
| `typecode` | Исходный код типа; группировка без справочного подменивания |
| `market_segment` | Исходный сегмент; группировка, пропуск отдельной категорией |

Смысл C40 принимается из постановки исходного проекта; геометрия и соответствие точки нужному событию здесь не доказываются. Порядок первого элемента `attempt_times` был проверен прежним аудитом, но текущий ноутбук не реконструирует траектории. Неполные ключи и пустые списки попыток останавливают выполнение.

## Выходные показатели

`rows` – число записей; `goa` – число меток True. `goa_pct` имеет знаменатель `rows` соответствующей группы и этапа. `retained_pct` сравнивает объем с исходным объемом; показатели сохранения по меткам используют исходное число соответствующей метки. `composition_pct` – вес группы в полном объеме этапа. `delta_goa_pp` и `composition_delta_pp` выражены в процентных пунктах. `outside` – разность источника и финала. При нулевом знаменателе доля остается NaN.

В `rule_overlap.csv` поле `not_before` означает отсутствие подтвержденного строгого отношения C40 < первая попытка, включая пропущенное время. Это не отдельная исключающая причина; взаимоисключающие причины находятся в `exclusive_reasons.csv`.

## Публичное распространение

Для отдельного проекта нужно документировать происхождение и лицензию исходного набора, доступ к промежуточным файлам и способ их воспроизведения. Эти условия здесь не предполагаются автоматически. Текущий контракт позволяет запуск на подготовленных артефактах; он не является автономным загрузчиком и всей цепочкой подготовки с нуля.
