# Что показал первый baseline

Подготовка сохранена коммитом 6cea578. Baseline выполнен по зафиксированному
плану: fit train, выбор validation, фиксированный test, без новых исключений.

| Test, 546 577 записей / 1 739 GoA | AP | ROC-AUC | Brier |
|---|---:|---:|---:|
| Константная вероятность из train | 0,003182 | 0,500000 | 0,003171649 |
| Геометрия C40 + UTC + аэропорт | 0,003759 | 0,562344 | 0,003171104 |
| Тот же набор + исходные типы самолетов | 0,003980 | 0,572297 | 0,003171014 |

Все восемь кандидатов сошлись. Validation выбрала C=0.01 для geometry и C=0.1
для geometry_aircraft. Пороги F1 validation зафиксированы до test.

Для geometry_aircraft − geometry парный bootstrap 23 недель / 1000 повторов
дает 95% интервал AP [0,00002415; 0,00047636], ROC-AUC [0,002290; 0,018112].
Разница ранжирования положительна в этом способе оценки. Интервал Brier
[-0,0000002014; 0,0000000269] включает ноль: устойчивое преимущество Brier
здесь не установлено. Интервалы условны относительно фиксированных моделей;
недельные блоки не учитывают всю зависимость по самолетам.

Практическая способность обнаружения слабая. При зафиксированном пороге
geometry_aircraft находит 35 из 1739 GoA (recall 2,01%), дает 9500 ошибок FP,
precision 0,367%. Geometry находит 768 GoA, но дает 187348 ошибок FP
(recall 44,16%, precision 0,408%, доля тревог 34,42%). Улучшение AP не делает
ни один из этих режимов эксплуатационно полезным автоматически. Порог F1
не задает стоимость ошибок. Порог не менялся после просмотра test.

Аэропортовые изменения неоднородны; общий рост AP не означает улучшение для
каждого аэропорта. EGCC в test отсутствует. Test — неполный 2023 год,
преимущественно знакомый парк. Доступность C40 / метаданных в реальном времени
не подтверждена. Связь типов с меткой не является причинной оценкой.

Исходный parquet и split неизменны по SHA256. Локальные коэффициенты и test-
прогнозы исключены из Git. Все восемь ноутбуков и балансы проверены.
Дальше разумно разобрать диагностические ошибки и календарное / аэропортовое
изменение порога без настройки модели по test. Для следующего подбора потребуется
новый независимый финальный период; дополнительные тестовые метрики нельзя
использовать как скрытую validation.
