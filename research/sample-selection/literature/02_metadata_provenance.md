# Происхождение календарного провала метаданных

Проверка: 10 октября 2026. [Карточка Zenodo](https://zenodo.org/records/10210178)
описывает сочетание OpenSky и EUROCONTROL Network Manager, перечисляет
market_segment как сегмент перевозок и AC_CLASS как класс самолета.
Карточка не объясняет границу заполнения market_segment в январе 2023.
Локальный словарь `europe/docs/data_dictionary.md` связывает market_segment
с обогащением EUROCONTROL; историческая доступность остается неподтвержденной.

Независимое чтение ноутбуком 05 показывает одинаковую последнюю непустую запись
market_segment в источнике и финале: landing_time 2023-01-01 10:44:36 UTC.
В финале за 2023 год есть только 100 непустых market_segment: Mainline 94,
Lowcost 5, Cargo 1; 546 478 записей имеют null. Это не локально созданный
провал: он уже наблюдается в файле источника с проверенным SHA256.
Почему он возник при формировании опубликованного набора, не установлено.
Не следует приписывать его сбою EUROCONTROL или изменению правил без свидетельств.

AC_CLASS физически заполнен в финале, включая код ZZ (147 записей в 2023).
Смысл кодов здесь не расшифровывается без таблицы источника; их наличие не
подтверждает качество классификации. Все значения сохранены в отчете частот.

Методологическое следствие: обязательный market_segment делает поздний период
непредставленным. Набор без него следует рассматривать отдельным условным
сценарием. Решение об основном наборе требует проверки времени получения
полей и исторических справочников; этот аудит не утверждает готовность для
операционного прогноза. Пустые значения не восстанавливаются из будущих исходов.
