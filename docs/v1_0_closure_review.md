# Финальный обзор Approach Risk ver. 1.0

Дата: 11 октября 2026. Обзор выполнен для закрытия проекта, без нового обучения.

## Результат обзора

Проект содержит завершённые исследовательские линии: аудит и подготовку Европы, геометрию и восстановление траекторий, отбор выборки, подготовку и чувствительность METAR, Logistic и CatBoost на C40. Начальная инвентаризация конечного захода сохранена как мост к версии 1.1; модель новой постановки не обучалась.

Корневой README переписан по итоговым отчётам: устранены устаревшие утверждения, что отбор и погодное обучение ещё не выполнялись. Указаны реальные метрики, ограничения, статус закрытия и план преемственности данных. Исторические README и протоколы внутри линий сохраняют последовательность этапов; их слова «следующий этап» не означают разрешение продолжать закрытый проект.

## Проверено заново

- Все локальные ветки являются предками main после слияния research/final-approach-dynamics. Это слияние также включило research/boosting-weather-comparison. Слияние: 4ceed7d. Ветки не удалялись.
- scripts/verify_shared_architecture.py: 93 файла, 6 331 485 строк, разбиение и метки; совпадение извлечённых признаков с прежней реализацией и воспроизведение сохранённых метрик. Обучение не выполнялось.
- research/boosting-weather-comparison/scripts/verify_training.py: десять кандидатов, хеши 42 файлов, выбор по validation, метрики validation/test, по 1000 прогнозов выбранных моделей, важности и исполненные ячейки. Проверка завершилась успешно без обучения.
- Обследованы 1482 отслеживаемых файла и 97 ноутбуков. Инвентаризация: v1_0_review_inventory.json.
- Итоговые числа README сверены с отчётами Logistic, CatBoost, METAR, отбора и эксперимента Эрмита. 118,43 м относятся к модели этапа 11 (линейная интерполяция с ML-поправкой), а не к чистой линейной интерполяции.

## Ограничения и исторические артефакты

Один ноутбук содержит сохранённую ошибку ModuleNotFoundError: pyarrow: europe/notebooks/06_attempts/multiple_attempts/06_05_three_attempt_cases.ipynb, ячейка 3. Это исторический сбой ядра, а не новый результат. Он сохранён прозрачно; успешный полный повтор этого ноутбука при закрытии не заявляется.

Шесть ноутбуков не имеют отметок выполнения кодовых ячеек: 07_04_weather_comparison, 07_05_composition_missing, 07_06_c40_distributions, 07_07_c40_geometry, 07_08_c40_radial_cases и EGCC/07_03_egcc_february. Список полных путей в инвентаризации. Их наличие не равнозначно исполненному исследованию; отчёты и тематические последующие исследования оцениваются отдельно.

Оценка GoA ограничена исходной разметкой, покрытием C40, ранее просмотренным test и неизвестным фактическим временем получения METAR. Независимая эксплуатационная валидация отсутствует. Низкая полнота при большом числе ложных предупреждений не позволяет заявить готовую диспетчерскую систему.

Полное воспроизведение всех исторических исследований и обучение всех моделей заново не выполнялись. Обзор охватывает структуру, документированные результаты, состояние ноутбуков и ключевые проверки данных и классификаторов; это не построчный аудит всех алгоритмов.

## Публикация и преемственность

По перечню отслеживаемых файлов не обнаружены сырые Parquet, бинарные модели, корневые Articles или Checkpoint. PDF в списке публикационного просмотра — экспортированные исследовательские рисунки, а src/approach_risk/data — исходный код. Это проверка текущего дерева, не аудит секретов всей истории Git.

Git remote в момент обзора не настроен. Push не выполнялся. Финальная документация просмотрена пользователем; после минимальных правок подготовлен коммит закрытия. Push ожидает URL репозитория.

В 1.1 будут выборочно перенесены данные, проверенные загрузчики и нужные проверки с указанием версии и происхождения. Новая постановка требует отдельного подтверждения наличия последовательных наблюдений конечного захода, в том числе GoA.

Для портфолио остаются полезны два самостоятельных результата: геометрический аудит авиационных метаданных и сравнение восстановления траекторий. Согласованы c40_geometry, goaround-metar (отбор и качество METAR), goaround-weather-classification (Logistic и CatBoost), us-goaround-research (США 2019 с европейской частью в архиве). Это исследовательские проекты, не готовые системы предупреждений. Самостоятельные репозитории пока не созданы и не опубликованы.
